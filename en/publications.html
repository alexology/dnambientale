Software

Tools we develop

Open source packages and pipelines born from the group's work, designed to be reused by other labs.

aasv

R package for Windows that assesses whether COI metabarcoding sequence variants (ASVs) represent authentic biological sequences: downloads reference data from BOLD, aligns at the amino acid level, and produces a functionality index.

R v0.1.0 GPL-2+
View repository →

metabarpipe

Organized R pipeline for Windows that leverages vsearch and cutadapt to process environmental metabarcoding data.

R v0.1.1
View repository →

biomonitoR

R package to manage taxonomic and functional information and compute biomonitoring indices for running waters, with a focus on the macroinvertebrate community.

R v0.9.3 GPL-2.0
View repository →
